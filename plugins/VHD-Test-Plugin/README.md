# VHD Test Plugin 0.5.0

Validation plugin for Vanilla HTML Designer 0.7.4+.

The **Note plugin** now tests:

- grouped Properties sections;
- `textarea`;
- `url`;
- the existing `color`, `number`, `select`, and `checkbox` fields;
- HTML round-trip import/export.

After adding and selecting the block, the Properties panel should show two
sections:

- **Contenu**
- **Présentation**

The content section contains a multiline text field and URL field.
